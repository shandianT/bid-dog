常见问题

装之前想知道的

macOS 提示「已损坏,无法打开」?

不是文件坏了,是系统对未签名应用的默认拦截。拖入「应用程序」后,终端执行 xattr -cr /Applications/中标狗.app;或在「系统设置 → 隐私与安全性」点「仍要打开」。

我的标书和素材会上传到哪里吗?

不会。所有文件存在你电脑的「文稿/中标狗」文件夹,程序本地运行。只有你主动绑定的生成引擎/模型网关会按你的配置被调用。

不绑定任何 AI 能用吗?

能。内置演示模式完整走通建任务、12 阶段、对话、产出、出件检查全流程。产真实标书时再绑定 SoWork / Claude Code / Codex 任一引擎。

生成用的是谁的额度?

生成标书本体走你绑定的 CLI 订阅额度;「模型接入」里的 API Key 只用于对话追问与图片打标——两个独立额度,用完会明确提示,不是甩一串英文。

怎么更新版本?

下载新安装包覆盖安装即可,数据与配置自动保留,老版本数据目录会自动迁移,任务与素材一个不丢。
