常见问题

装之前想知道的

第一次使用要做什么?

下载安装后，粘贴发放的 Key，点一次「测试连接」，再上传招标文件即可。没有 Key 也能先打开在线体验或运行内置演示，不需要先学习模型和命令行配置。

我的标书和素材会上传到哪里吗?

原始文件和产物存在你电脑的「文稿/中标狗」文件夹，不上传到中标狗自有服务器。生成时所需的文本或图片会发送给你主动绑定的模型服务，请同时遵守该服务的数据规则。

不填写 Key 能用吗?

能先用内置演示完整走通流程；产真实标书时粘贴发放的 Key，即可完成完整生成。

生成用的是谁的额度?

使用发放的 Key 时，生成、追问与识图都走对应套餐；应用会自动使用内置 OpenCode，无需另装 Node.js，也无需登录 OpenCode 账号。你也可以在高级设置里改用自己的 SoWork、Claude Code 或 Codex 订阅。

怎么更新版本?

等当前任务结束后从托盘真正退出旧版，再下载新安装包覆盖安装。数据与配置会自动保留，老版本数据目录也会自动迁移。

macOS 提示「已损坏,无法打开」?

文件并没有损坏。当前安装包尚未使用 Apple Developer ID 完成公证，macOS 会对每次新下载或覆盖安装重新加隔离标记；在商业证书配置完成前，代码本身无法冒充系统公证。更新前先从托盘退出旧版，把新版拖入「应用程序」并替换、推出 DMG 后执行下面命令；也可到「系统设置 → 隐私与安全性」点「仍要打开」。

xattr -dr com.apple.quarantine "/Applications/中标狗.app"
