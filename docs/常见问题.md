# 中标狗 · 常见问题

## 安装后能直接用吗？

可以直接体验界面和内置演示流程，不需要 Python、Node.js、API Key 或 CLI。要生成真实标书，需要安装并登录 Claude Code 或 Codex CLI，或者配置自定义 Agent 命令。

## 还需要单独下载标书技能包吗？

不需要。v0.11.1 安装包已经内置标书技能包，首次使用时由应用自动准备。

## 为什么 Mac 提示“已损坏”？

当前安装包尚未进行 Apple 签名和公证，macOS 会拦截从网络下载的未签名应用。请按照 [Mac 安装说明](Mac安装说明.md) 放行。

## Windows 为什么出现 SmartScreen？

当前安装程序尚未配置商业代码签名。确认文件来自本仓库 Release 后，选择“更多信息 → 仍要运行”。

## 为什么找不到 `codex` 或 `claude`？

先确认对应 CLI 已安装、已登录，并能在系统终端正常启动。中标狗会自动查找 Homebrew、npm 等常见安装位置；安装或登录完成后请重开中标狗。

## 为什么桌面端不再显示“下载”？

桌面端会直接调用系统默认应用打开产物，避免在“下载”目录生成重复副本。任务完成后也可以一键打开最终 Word 或整个任务文件夹；网页模式仍使用下载。

## 数据保存在哪里？

任务、日志和素材默认保存在用户“文稿/中标狗”目录中。素材库可以切换到其他目录或共享盘。

## 数据会自动上传吗？

本地任务与素材默认保存在本机。是否向外部服务发送内容，取决于用户选择的 Claude Code、Codex CLI、模型网关或自定义引擎。涉密项目请遵守组织的数据安全要求。

## 生成结果能直接投标吗？

不能跳过人工审核。至少要核对投标主体、报价、资质有效期、技术参数、偏离情况、服务承诺、签章、页码和递交要求。

## 删除任务后能恢复吗？

不能。删除任务会删除其招标文件和生成产物，重要项目请先备份。

## 如何反馈问题？

请提交 [Issue](https://github.com/shandianT/bid-dog/issues)，说明操作系统、中标狗版本、生成引擎和复现步骤。请勿公开 API Key、客户资料、报价、证件或完整标书。
