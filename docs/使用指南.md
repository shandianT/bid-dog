# 中标狗 · 使用指南

## 1. 安装并启动

从 [Release](https://github.com/shandianT/bid-dog/releases/tag/desktop-v0.11.2) 下载对应系统的安装包。打开应用后等待左下角显示“本地引擎 v0.11.2 · 已连接”。

## 2. 选择生成引擎

进入“设置 → 模型接入 → 生成引擎”：

- **内置演示流程**：无需配置，用于体验 12 阶段交互，不生成可直接投标的真实标书。
- **Claude Code**：本机安装并登录 `claude` CLI 后选择。
- **Codex CLI**：本机安装并登录 `codex` CLI 后选择。
- **自定义命令**：适合接入其他本机 Agent。

标书技能包已经内置在安装包中，无需单独下载或解压。

## 3. 准备素材库

建议放入经过确认的公司介绍、产品资料、资质与案例、项目图片、应答口径和历史标书。事实数据以素材库为准；缺失内容应保持“需补充”，不要让 AI 编造。

素材库默认保存在本机，也可在应用中改到共享盘。修改位置不会自动搬迁旧文件。

## 4. 新建任务

把 PDF、DOCX 或 Markdown 招标文件拖入窗口。按照 Agent 的问题补充资料和关键选择，也可以给当前任务添加参考标书。

## 5. 检查与出件

任务完成后，先点击“打开最终 Word”，再处理检查报告中的红色事项。右侧产物已按“最终交付、检查报告、分析依据、过程稿件”整理，每个文件旁会说明用途；也可以点击“打开任务文件夹”查看全部结果。正式提交前，必须人工核对报价、资质、参数、承诺、签章和递交要求。

## 数据位置

- macOS：`~/Documents/中标狗/`
- Windows：用户“文档\中标狗”目录
- 任务产物：`中标狗/jobs/<任务>/`
- 默认素材库：`中标狗/素材库/`
